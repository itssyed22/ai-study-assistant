# AI Study Assistant

An AI-powered study companion that turns raw notes into summaries, quiz questions, and answers — built with Streamlit, LangChain, and Groq's LLaMA 3.3.

## Features
- Paste any notes or text
- Get a concise AI-generated summary
- Auto-generate quiz questions to test yourself
- Ask follow-up questions about the material

## Tech Stack
- Python
- Streamlit (UI)
- LangChain (orchestration)
- Groq API (LLaMA 3.3 inference)
